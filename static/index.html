Step 1 Words to Numbers: Tokenization
The Plain English Reality: Computers cannot read letters like 'H', 'e', 'l', 'l', 'o'. Before anything happens, the sentence is sliced into frequent letter pieces called tokens, and each piece is assigned a unique integer ID from 0 to 49,151.
"The" → ID: 504
→
" moon" → ID: 6128
→
" reflects" → ID: 15478
SmolLM2-135M holds an internal dictionary of 49,152 vocabulary tokens. Notice the space character 0x20 at the beginning of words—in tokenizers, leading spaces are part of the token itself!
Step 2 Numbers to Coordinates: Safetensors Row Lookup
The Plain English Reality: An ID like #6128 has no intrinsic meaning. To give it meaning, the model opens its model.safetensors weight file, travels directly to Row 6128, and copies out 576 numbers.
Token ID #6128
→ Lookup Row 6128 →
[+0.12, -0.04, +0.81, ..., -0.22] (576 Floats)
This 576-dimensional vector acts like a GPS coordinate inside the model's mind. Related words like "ocean" and "water" land physically close to each other in this 576-dimensional geometry.

Step 4 Picking the Winner: Softmax & Probabilities
